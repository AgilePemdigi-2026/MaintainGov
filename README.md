# MaintainGov

MaintainGov membantu tim maintenance mengolah feedback pengguna menjadi case, backlog, dan pekerjaan pengembangan yang terhubung dengan pull request di GitHub.

Repository ini memuat rencana kerja **Kelompok 5** untuk **Sprint 1, Week 10-11**. Fokus sprint pertama adalah login, pembatasan hak akses, logout, dan analisis feedback dari CSV. Aplikasi akan menggunakan Next.js/TypeScript, Laravel, FastAPI, dan MySQL.

Pembagian tugas dan keputusan proyek ada di [Master Plan](docs/MASTERPLAN.md). Untuk mulai mengerjakan tugas minggu ini, lihat [Eksekusi Week 10](docs/WEEK10_EXECUTION.md).

Status implementasi dicatat pada [Progress Tracker](docs/PROGRESS_TRACKER.md). Target dalam rencana kerja belum dihitung sebagai fitur selesai sampai ada hasil pengujian dan demo. Keputusan yang masih terbuka dibahas saat koordinasi kelompok.

Gunakan template di `.github/` saat membuat issue dan pull request. Satu tugas memiliki satu penanggung jawab dan satu reviewer; bantuan antaranggota tetap diperbolehkan.
